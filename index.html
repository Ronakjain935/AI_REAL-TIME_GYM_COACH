⚡ Deploying Landing Page to Netlify

Deploying this project's landing page on Netlify is seamless. Netlify provides lightning-fast global CDN hosting, automatic SSL certificates, and continuous deployment from Git.

Deploy to Netlify Now
# netlify.toml Configuration File

[build]
publish = "."
command = "# Static site - no build required"

[[headers]]
for = "/*"
[headers.values]
X-Frame-Options = "DENY"
Permissions-Policy = "camera=*"

[[redirects]]
from = "/api/*"
to = "/index.html"
status = 200
Got Questions?

Frequently Asked Questions

How do I deploy this landing page to Netlify?

1. Push your code to GitHub.
2. Log into Netlify and click "Add new site" -> "Import an existing project".
3. Connect your repository. Netlify will automatically detect the netlify.toml file and deploy the landing page instantaneously.

Does pose tracking require sending camera feeds to a cloud server?

No! MediaPipe Pose tracking executes locally in your browser/local Python process using WebRTC. Your camera stream remains completely private.

How does the AI Voice Coach work?

When sets are completed or form anomalies are detected, the Groq LLaMA-3 LLM synthesizes personalized encouragement and tips, which are converted to voice audio via gTTS.

How do I run the Python Streamlit app locally?

Install dependencies via pip install -r requirements.txt and run streamlit run main.py.
